Агент генерации кода на C++, работающий полностью локально: без обращения
к внешним API и без передачи данных наружу.

<!--more-->

Агент построен поверх llama.cpp с моделью Qwen2.5-Coder и альтернативным
запуском через Ollama.

Реализовано:

- конвейер обработки запроса, генерации и валидации полученного кода;
- цикл итеративного улучшения результата;
- работа без сетевых зависимостей — весь inference выполняется на машине
  пользователя.

Проект интересен точкой пересечения двух областей: языковая модель здесь
не сервис, к которому обращаются по сети, а библиотека на C++, встроенная
в программу.

A study library: simplified analogues of standard library components, written
from scratch in order to understand how they work inside.

<!--more-->

What is implemented:

- analogues of standard library containers and algorithms;
- template algorithms and data structures;
- a parser for arithmetic expressions that builds a syntax tree;
- optimisation of memory operations and data access.

The point of the exercise is not to replace the standard library but to
understand what it is made of: how ownership of memory works, how copying
differs from moving, and what a template expands into.

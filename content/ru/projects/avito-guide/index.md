Командный проект хакатона «Лаборатория кода» от Авито: система, которая
показывает пользователю подсказки прямо во время работы с интерфейсом.

<!--more-->

Платформа состоит из встраиваемого виджета, тестового классифайда, админки
для управления сценариями, backend API и аналитики прохождения.

Мой вклад:

- эндпоинты публикации и таргетинга на Go: подбор сценария по маршруту,
  контексту пользователя и приоритету;
- встраиваемый виджет на TypeScript и его связка с API;
- тестовый классифайд на React с якорями онбординга и передачей контекста
  страницы в виджет;
- разворачивание всего стека в Docker Compose и настройка CI
  на GitHub Actions.

Проект вышел в финал хакатона.
